

# 双光摄像头可见光-红外双摄空间对齐与实时融合系统

针对物理双摄由于空间位置差异导致的视差问题，通过多视角同步抓拍、亚像素级交互式特征点标定，以及基于 RANSAC 的单应性变换（Homography）算法，实现了两路视频流的较高精度空间对准，并支持去黑边的自动视野裁剪与实时半透明融合。

## 核心原理 

双路摄像头由于光心位置不同，在拍摄同一场景时会产生视差。在假设目标场景近似为平面（如平整墙面、标定板）或相机间距远小于景深的情况下，两幅图像之间的几何映射关系可以通过一个 $3 \times 3$ 的**单应性矩阵 (Homography Matrix, $H$)** 来严格描述。

给定红外图像上的像素点坐标 $P_{ir} = (x_{ir}, y_{ir}, 1)^T$ 和可见光图像上的对应点坐标 $P_{vis} = (x_{vis}, y_{vis}, 1)^T$，其变换关系满足：


$$P_{vis} = H \cdot P_{ir}$$

设计分为两个阶段：

1. **离线标定阶段**：通过采集多组共视平面的特征点对，利用最小二乘法结合 RANSAC（随机抽样一致性）算法，剔除误匹配的离群点，解算出最优变换矩阵 $H$。
2. **实时对齐阶段**：利用解算出的矩阵对红外视频流进行透视变换，使其空间坐标系与可见光摄像头严格重合，从而实现多模态数据的空间对齐。

## 实现办法与核心特性

改善了对齐精度问题，引入可操作功能：

* **高精度交互式标定工具**
* 摒弃了传统 OpenCV 脚本只能粗糙点击的弊端，开发了基于状态机的鼠标-键盘联合交互系统。
* **像素级微调**：支持选中特征点后，使用 `W/A/S/D` 键进行单像素级别的上下左右平移，极大降低了鼠标点击带来的不可控人为误差。
* **动态点位管理**：实现了特征点的就近吸附激活、`Z` 键撤销机制，确保标定过程的容错率。


* **多图联合鲁棒计算**
* 支持多组图像的同步抓拍，允许在一次标定过程中引入不同视角的特征点对，增加约束方程的数量，使得最终计算出的单应性矩阵在全局视野下更加平滑和鲁棒。


* **动态视野锁定与自动裁剪**
* 经过透视变换后的图像不可避免地会产生畸变和不规则黑边。实时推理脚本中引入了自动掩码侦测算法，通过灰度阈值化和连通域最小外接矩形计算，**仅在启动时计算一次**最大有效公共重叠区域。
* 算法内置了安全边距机制，彻底裁除黑边，确保最终输出画面的纯净度，同时避免了每帧重新计算 ROI 带来的算力消耗。


* 基于 `cv2.addWeighted` 实现零拷贝的内存级图像融合。
* 实时计算并渲染 FPS，支持通过键盘热键热切换可见光、红外及半透明融合状态，便于动态观察对齐效果。



## 操作指南 

### 环境依赖

```bash
pip install opencv-python numpy
```

*注：请根据实际硬件情况，在代码中修改 `VIS_CAMERA_ID` 和 `IR_CAMERA_ID`。*

### Step 1: 运行标定程序 (`v2_calibrate.py`)

该步骤用于解算空间位置矩阵并生成配置参数文件。

1. **多视角抓拍**：
* 将双摄模组对准有丰富纹理的平整墙面或标定板。
* 按 `SPACE`（空格键）抓拍当前同步画面（建议在不同角度和距离抓拍 3-5 组）。
* 按 `C` 结束抓拍，进入特征点标注环节。


2. **特征点精标**：
* 在左右两个窗口中，用鼠标**左键**依次点击相同位置的特征点（如墙面污点、角点）。
* 点击已有特征点可重新激活它，此时可使用 `W/A/S/D` 进行像素级微调，或用 `Z` 删除。
* 当前图片标注完成后，按 `N` 进入下一张。


3. **矩阵计算与保存**：
* 标注完所有图片后，系统会自动运行 RANSAC 算法计算矩阵并弹出融合预览图。
* 确认对齐效果良好后，按 `S` 键保存矩阵至 `ir_to_vis_homography.npy`。



### Step 2: 运行实时对齐程序 (`live_alignment_test2.py`)

该脚本将加载标定好的矩阵，进行实时的自动裁边与流融合。

1. 直接运行脚本，终端将提示 `✅ 成功加载对齐矩阵` 并自动打印出侦测到的公共重叠坐标（ROI）。
2. **快捷键控制**：
* `W`：纯可见光模式 (Alpha = 1.0)
* `S`：纯红外模式 (Alpha = 0.0)
* `A`：多模态半透明融合模式 (Alpha = 0.5)
* `Q` / `ESC`：安全退出程序



## 文件结构

* `v2_calibrate.py`：交互式标定与矩阵计算脚本。
* `live_alignment_test2.py`：实时多模态推流、自动裁剪与融合脚本。
* `ir_to_vis_homography.npy`：（由程序生成）存储最终空间映射关系的 NumPy 权重文件。

# 十分要注意的事项
* 注意可见光和红外摄像头ID不能写反，两个有顺序的，写反没有对齐效果
* 目前的`ir_to_vis_homography.npy`是我已经标定过一遍生成好了，用了4张图片，然后用格子天花板标定的，然后效果感觉还可以，对于非常近处的有视差，但是稍远一些效果还不错，无人机应该一般不会太近，所以这个效果应该可以了
* 如果要自己尝试再标定，需要用摄像头实拍办法标定，参考`v2_calibrate.py`
* 这类轻量化方法还不能解决两个摄像头因为位置导致遮挡不同，然后语义分割的模型需要训练，所以这个方法目前只能解决视差问题，不能解决物体重叠遮挡问题，遮挡问题可能需要语义分割那种模型来解决。
